1. Introducción 
Rapitrip es una microempresa orientada a la comercialización de productos y a la gestión de 
servicios asociados con la preparación, coordinación y entrega de pedidos. Como parte de su 
proceso de evolución tecnológica, se plantea el desarrollo de una plataf orma digital que permita 
integrar en un mismo entorno las actividades de comercio electrónico dirigidas al cliente y las 
funciones administrativas y operativas necesarias para controlar la oferta comercial, el inventario, 
los pedidos y las entregas. 
El presente documento corresponde al primer entregable del proyecto y comprende las actividades 
de análisis, modelado y diseño inicial del sistema de información de Rapitrip. Para ello, se parte 
de las necesidades y requerimientos establecidos para la plat aforma, a partir de los cuales se 
determinan las funcionalidades esperadas y las condiciones de calidad que debe cumplir el sistema. 
Asimismo, se consideran los distintos actores que intervienen en su funcionamiento, entre ellos el 
Cliente, Administrador, Encargado de Pedidos y Repartidor, definiendo las responsabilidades e 
interacciones correspondientes a cada uno. 
Como parte del modelado del sistema, se desarrollan diagramas de casos de uso a nivel de negocio 
y de sistema, con el propósito de representar las funciones y relaciones existentes entre los actores 
y los procesos definidos. De igual manera, se incorpora un diagrama de clases para representar la 
estructura conceptual de los principales elementos que intervienen en la solución.  
Como parte del diseño de la interacción con la plataforma, la navegación y la presentación del 
sistema se integran mediante un prototipo navegable desarrollado en Figma. Este prototipo 
contempla los cuatro actores definidos para el sistema Cliente, Adminis trador, Encargado de 
Pedidos y Repartidor , permite representar visualmente las interfaces correspondientes a sus 
funciones, así como los recorridos y transiciones entre las diferentes pantallas. De esta manera, el 
prototipo constituye una representación conjunta de la estructura navegacional y de la presentación 
prevista para el sistema, permitiendo comprender de forma más cercana cómo interactuarán sus 
usuarios con la futura solución.

Finalmente, se presenta el modelo Entidad–Relación de la base de datos de Rapitrip, mediante el 
cual se representa la estructura y vinculación de la información necesaria para sustentar las 
funcionalidades planteadas.  
2. Objetivos 
2.1. Objetivo general 
Realizar el análisis, modelado y diseño del sistema de información de Rapitrip, a partir de las 
necesidades y requerimientos de la organización, con el propósito de establecer una solución de 
software estructurada que responda a sus procesos comerciales, administrativos y operativos. 
2.2. Objetivos específicos 
1.  Identificar las necesidades y requerimientos planteados por la dirección de Rapitrip para 
el sistema, con el propósito de establecer las funcionalidades, condiciones y características 
que deberá contemplar la solución propuesta. 
2. Modelar las funcionalidades del sistema mediante diagramas de casos de uso, 
representando los actores involucrados, las funciones disponibles para cada uno de ellos y 
las relaciones existentes entre los diferentes casos de uso. 
3. Representar la estructura conceptual del sistema mediante un diagrama de clases, 
identificando las principales clases, atributos, operaciones y relaciones derivadas de las 
funcionalidades definidas para Rapitrip. 
4. Diseñar un prototipo navegable del sistema mediante Figma que integre su navegación y 
presentación, representando las interfaces, recorridos e interacciones correspondientes al 
Cliente, Administrador, Encargado de Pedidos y Repartidor de acuerdo con las fu nciones 
establecidas para cada actor. 
5. Presentar el modelo entidad -relación de la base de datos de Rapitrip, mostrando las 
entidades, atributos, claves y relaciones necesarias para estructurar la información utilizada 
por las funcionalidades definidas para el sistema
